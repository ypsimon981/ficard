# FiCard

Repository dedicato a FiCard.

Android: istruzioni in [docs/android-pubblicazione.md](docs/android-pubblicazione.md). `npm ci`, `npm run android:prepare`, poi `npm run android:open`. Build APK di prova in GitHub Actions; nessuna firma release o pubblicazione automatica su Google Play.

La web app vive direttamente nella root del repository. La base iniziale è stata migrata dalla precedente cartella `fi-card/` del repository legacy, così FiCard può evolvere separatamente dagli altri progetti.
